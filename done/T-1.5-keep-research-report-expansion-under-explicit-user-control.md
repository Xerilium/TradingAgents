## User requirement
User reports automatic expansion makes Agent research hard to read. Sections must open only on explicit user action; no automatic expansion during selection, rendering, or background updates.

## Evidence
Shared-browser UAT: switching from META to AAPL opened Portfolio decision automatically. Source tradingagents/web/static/app.js renderReports uses openReportNames.has(name) OR (!openReportNames.size && i===0), forcing the first section open when none are selected. The toggle handler removes collapsed sections from that set, so an empty set cannot distinguish an intentional collapse-all from default initialization.

## Acceptance
Start new report views collapsed. Preserve explicit open/closed choices and reading position across background updates. Closing every section must remain closed after rerender. Switching ticker/run must not unexpectedly expand sections or jump scroll. Keep disclosures keyboard accessible and source artifacts available. Record failing UI/state tests, implement, independently audit, and UAT visibly in shared browser. No research reruns, orders, or unrelated redesign required.
