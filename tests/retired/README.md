as it existed before retirement. It is deliberately outside pytest collection:
the user explicitly replaced its broad research-approval requirements with
T-1.10 per-post social classification. This is a scope change, not a passing
result or weakened model benchmark.

submission. Current regressions in `test_laya_social_contract.py` establish the
opposite: Laya is source evidence; completed research and deterministic trading
